# FPS Bedwars

Competitive multiplayer first-person survival shooter for Roblox: Bedwars rules (team islands, beds, last team standing) with Rust-inspired gunplay, building and atmosphere.

## Layout
- `src/`: Rojo-synced Luau (`client`, `server`, `shared`), see `default.project.json`
- `blender/`: Blender generator scripts and `.blend` sources
- `exports/`: FBX meshes imported into Studio
- `scripts/`: Studio-side Luau tools (map builder, checks)
- `docs/`: design specs and implementation plans

The local working copy lives in the Obsidian vault at `C:\Roblox Dev\FPS Bedwars`, next to the project notes.

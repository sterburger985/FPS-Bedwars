# FPS Bedwars Map Build — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved floating-island FPS Bedwars map (5 team islands, center island, 5 resource platforms, structures, materials, lighting) in the "FPS Bedwars" Studio place.

**Architecture:** Geometry is modelled by Python generator scripts in Blender 5.2 and exported as FBX, one object per material. FBX files come into Studio through the Import 3D window as templates in `ServerStorage.MapAssets`. A Luau `MapBuilder` stamps templates into `Workspace.Map` at exact 72° steps, adds collision floors, tags and environment, and a Luau `MapChecks` asserts the layout rules. Surfaces use Roblox MaterialVariants (seamless, scale-locked tiling) instead of UV textures.

**Tech Stack:** Blender 5.2 Python (bpy, bmesh), FBX, Roblox Studio + Luau via the Studio MCP connector, MaterialService/MaterialVariant, CollectionService, Terrain water, Rojo 7.7.

**Spec:** `docs/superpowers/specs/2026-10-25-map-design.md`

## Global Constraints

- 1 Blender unit = 1 stud. Blender +Z up → Roblox +Y up. Island-local "front" (toward map center) = Roblox −Z.
- 12-stud building grid. Starter shed 24 × 24 × 12, doorway 6 W × 9 H.
- Team island centers at radius 250, angles Red 90°, Blue 18°, Green −54°, Yellow −126°, Purple 162° (X = r·cos θ, Z = −r·sin θ).
- Team tops Y = 200, center top Y = 206, ocean Y = 0, kill height Y = 60.
- Team island flat build zone 120 × 96; center ≈ 180 across; platforms 36 × 36 at radius ≈ 202 on the half-angles.
- Every mesh ≤ 20,000 triangles; every MeshPart ≤ 2048 studs on any axis.
- Object names end in a material key: `_Rock`, `_Sand`, `_Rust`, `_Steel`, `_Concrete`, `_Wood`, `_Cloth`, `_Glow`, `_Glass`.
- Dispenser glow: amber (255, 170, 60) on platforms, cyan (60, 220, 255) at center. Team colours: Red (196, 52, 46), Blue (46, 98, 196), Green (60, 150, 64), Yellow (214, 176, 44), Purple (128, 64, 180).
- Tags: `Bed`, `Shop`, `ResourceDispenser`, `SpawnPad`, `BuildFloor`, `KillHeight`. Attributes: `Team` (string), `Tier` ("Basic" | "High").
- Never set `Lighting.Technology`. Set model pivots through `PrimaryPart.PivotOffset`, never `WorldPivot`.
- Keep Studio on screen during captures (white-capture gotcha).

## Review Focus

1. Seams between flat BuildFloor parts and the cliff rim mesh: a player walking to the edge must not drop through a gap → `MapChecks.edgeSeams` raycasts down every 4 studs along the build-zone border.
2. Bed reachability: roof, posts or door frame must not block the bed → `MapChecks.bedAccess` raycasts from 3 studs outside the doorway to the bed's centre (must hit the bed first).
3. Texture scale on large cliffs: one MaterialVariant across a 90-stud cliff must not look stretched or repetitive → visual check at 3 distances in Task 8, with `StudsPerTile` tuned.
4. Props floating or buried after placement → `MapChecks.grounded` raycasts down from each prop's base (gap ≤ 0.5).
5. Unequal team bases from per-island cliff variation → `MapChecks.symmetry` compares each team's BuildFloor area, shed/shop/spawn offsets (tolerance 0.05 studs).
